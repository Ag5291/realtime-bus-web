定位结果（来自 ctf.apk 反编译）

1) 实时公交入口
- 字符串资源：res/values/strings.xml 里 `home_center_rv_item_realtime_public_transportation` = “实时公交”。
- 点击处理逻辑在：ctf_apktool/smali_classes5/com/whpe/qrcode/shanxi/yangquanxing/view/fragment/home/HomeFragment.smali
  关键常量：
  https://apph5.ibuscloud.com/index.html?curPage=realTimeListPage&city=140300&appSource=com.ibuscloud.yangquanbus&userLng=
  并拼接 userLng/userLat 后通过 WebView 打开。

2) 打开方式
- 目标 Activity：com.whpe.qrcode.shanxi.yangquanxing.view.activity.webview.TitleContentWebViewActivity
- 通过 Bundle/Intent extra 传参：
  - `title` = “实时公交”
  - `content` = 上面的 H5 URL
- 该 Activity 内部最终执行：WebView.loadUrl(content)

3) 说明
- 这个“实时公交页面”不是打包在 APK 的 assets 里，而是线上 H5（题面所说“部署在 api 网页上”属实）。
- APK 里能提取到的关键内容是：H5 入口 URL、以及 H5 站点使用的接口域名/路径（在打包 JS 里）。
